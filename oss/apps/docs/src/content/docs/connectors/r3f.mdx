The react-three-fiber (R3F) connector. R3F renders three.js, so this package is a thin React layer
over [`@uptimizr/three`](/docs/connectors/three/) — it does not re-implement capture. It pulls the
live `scene`, `camera`, and `gl` (`WebGLRenderer`) from the R3F store via `useThree()` and hands
them to the three connector.

`react`, `@react-three/fiber`, and `three` are peer dependencies.

## Install

```bash
npm install @uptimizr/r3f @react-three/fiber react three
```

## Declarative component

Drop `<Uptimizr />` anywhere **inside** your `<Canvas>`:

```tsx
import { Canvas } from "@react-three/fiber";
import { Uptimizr } from "@uptimizr/r3f";

function App() {
  return (
    <Canvas>
      <Uptimizr projectId="your-project" endpoint="https://collect.example.com" />
      <YourScene />
    </Canvas>
  );
}
```

## Hook

For access to the `UptimizrClient` (read `sessionId`, emit custom events, stop early), call
`useUptimizr()` from a component rendered inside `<Canvas>`. It returns a ref whose `current` is the
client, and `null` until capture has started on mount:

```tsx
import { useUptimizr } from "@uptimizr/r3f";

function Telemetry() {
  const clientRef = useUptimizr({
    projectId: "your-project",
    endpoint: "https://collect.example.com",
  });
  // clientRef.current?.track("add_to_cart", { sku: "ABC-123" });
  return null;
}
```

Capture starts when the hook/component mounts and stops on unmount, tearing down every listener,
timer, and animation-frame callback — no cookies, no persistent IDs. World-space data is normalized
to the canonical wire frame by `@uptimizr/three`; the session is attributed to the `r3f` connector.

`disabled` is reactive, so it works as a consent flag: flipping it from `true` to `false` starts
capture and the reverse stops it. Other options are read when capture starts, and a change to the
R3F `scene`, `camera` or `gl` restarts it.

## WebXR and hit resolution

Both `<Uptimizr />` and `useUptimizr()` accept the three connector's full `trackScene` option set,
including the `xr` option: WebXR controller/gaze capture is on by default and idles until an
immersive session starts. The package re-exports three's `createSceneRaycaster`,
`createGazeRaycaster` and `createXrRaycaster` (see
[three.js → raycast probes](/docs/connectors/three/#raycast-probes)). To resolve XR rays to in-scene
hits, build a probe over the R3F scene and pass it through — see
[three.js → WebXR](/docs/connectors/three/#webxr) for the event mapping:

```tsx
import { useThree } from "@react-three/fiber";
import { createXrRaycaster, useUptimizr } from "@uptimizr/r3f";

function Telemetry() {
  const scene = useThree((s) => s.scene);
  useUptimizr({
    projectId: "your-project",
    endpoint: "https://collect.example.com",
    xr: { raycast: createXrRaycaster(scene) },
  });
  return null;
}
```
